Connector address
Shown when a key is created. Paste it in your AI assistant as a custom connector (remote MCP server, no sign-in), with the request header X-Api-Key and the key as its value.
Keys
The key is shown only once, copy it right away. It acts with your Dotclear permissions, never more. Revoke it at any time.
Read only
The assistant can read the blog but not write anything.
Header only
Recommended: the key is refused in the address, where it could end in the web server logs.

Optional lifetime of the key.
